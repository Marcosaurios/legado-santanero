## Architecture

Recipe site built with Astro (v7, Node 26, see `.nvmrc`), **server-rendered on Cloudflare Workers** with **EmDash** as CMS. EmDash is part of the same app: admin panel at `/_emdash/admin`, content in D1 (`DB` binding), media in R2 (`MEDIA` binding), see `wrangler.jsonc` and `src/worker.ts`. The only client JS is two small `<script>`s (Navbar toggles, search filtering).

### Data

- `src/types.ts`: `Recipe`, the single entity of the project.
- EmDash collection `recipes`, schema in `seed/seed.json` (also seeds the sample recipes). Field slugs are snake_case (`image_main`); `category` and `ingredients` are repeaters of `{ name }`. `emdash-env.d.ts` (entry types) is regenerated by EmDash on dev server start.
- `src/data/recipes.ts`: `getRecipes(locale)` calls `getEmDashCollection('recipes', …)` and maps entries with `toRecipe` (adds `url`, `translationGroup`). `getAllRecipes()` fetches every locale; `getCategories(recipes)`, `categoryUrl`, `alternates`, `recipeAlternates`, `categoryAlternates`.
- Each locale is its own EmDash entry, linked as translations (`translationGroup`). Translated categories are matched by position in the translated recipe's category list.
- Apply the seed to the local DB: `npx emdash seed seed/seed.json -d <.wrangler/state/v3/d1/.../*.sqlite> --skip-media`.

### Routing (bilingual, locale-prefixed)

```
src/pages/
  [...path].astro  → every localised page, rendered per request:
                     /es, /es/receta/:slug, /es/categoria/:name
                     /en, /en/recipe/:slug, /en/category/:name
  404.astro        → error page (Spanish, status 404)
```

`/` redirects to `/es` (`redirects` in `astro.config.mjs`). Astro `i18n` is configured (EmDash needs the locales) with `routing: 'manual'`; `src/middleware.ts` only exists because manual routing requires it. Don't enable `prefixDefaultLocale` (breaks EmDash's admin). Localised segment names live in `segments` in `src/data/recipes.ts`. Unknown paths are rewritten to the 404 page.

### Language switching

Each page computes `alternates: Record<Locale, string>` (its equivalent URL per locale, via EmDash translation groups) and passes it to `Layout` → `Navbar` → `LanguageDropdown`, which renders plain links.

### Search

`SearchList` (in `Layout`) renders every recipe of the locale hidden; its script filters by title on `#search-input` input and swaps `#search-results` with `#page-content`.

### Component structure (Atomic Design)

`src/components/{atoms,molecules,organisms,templates}`, `src/layouts/Layout.astro`.

### Styling

`src/styles/vars.scss` (variables + mixin `desktopView`) and `global.scss`. Component styles are scoped `<style lang="scss">`; `scopedStyleStrategy: 'class'` keeps them above the global `a:link` rules.

### i18n

`t(locale, 'components.x.y')` from `src/i18n/index.ts`, JSON files in `src/i18n/locales/{es,en}/`.

### Icons

FontAwesome Solid via `unplugin-icons`: `import House from '~icons/fa7-solid/house'` (Astro component).
